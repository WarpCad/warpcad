## Problem

Several tables and fixtures in `src/` are ported from the author's own JSCAD v1 libraries,
and `LICENSING.md` says nothing about them:

- `src/core/kernel/tables/rpi-parts.js`: from `jscad-raspberrypi@62a8e3b`
  (`src/rpi-parts.js`, `src/bplus-mounting.js`).
- `src/core/kernel/tables/fit-clearances.js`, `washer-specs.js`, `screw-specs.js`,
  `nut-specs.js`, `bolt-specs.js` and the generated `hardware-tables.generated.js`: from
  `jscad-hardware@1.1.0` and `@5.0.0`.
- `src/core/gear/__fixtures__/v1-gears.json`: measured output of `@jwc/jscad-gears` 2.0.0,
  generated by `scripts/generate-v1-gear-fixture.cjs`. No source is vendored (decision 6 in
  `docs/decisions/gears.md`: a clean reimplementation).
- `src/core/kernel/recipes/__fixtures__/group-snap-align.real-usage.md`: quotes from
  `PiPiece.jscad`.

The author wrote the V1 libraries, so relicensing the port under AGPL-3.0-or-later is theirs
to do, **unless** an outside contributor's work is inside them. The repository cannot show
that either way. The pre-publish review (2026-10-17) could not check it, and the user chose
to settle it before the push.

Two facts the review did find, to record rather than fix:

- `@jwc/jscad-gears` carries Rainer Hessmer's 2014 MIT notice in `src/gear.js`, and its
  `package.json` says `ISC`. WarpCad vendors none of that file (`docs/decisions/gears.md`,
  decision 6), so the notice does not attach here. The V1 package's metadata is a separate,
  upstream matter.
- Some fastener dimensions were first transcribed from vendor pages
  (`atlrod.com/metric-hex-bolt-dimensions/`, `americanfastener.com/cap-screws/`, cited in
  `bolt-specs.js`) or from ISO 7089 / ISO 4032 (cited by number in `washer-specs.js` and
  `nut-specs.js`). These are dimensional facts with their sources kept in comments.

## Proposed fix

1. **Owner step first (the agent cannot do this).** For each V1 repository the port draws on
   (`jscad-utils`, `jscad-hardware`, `jscad-raspberrypi`, `jscad-gears`, `PiPiece`), run
   `git shortlog -sne` in its local checkout and check its GitHub or GitLab pull-request
   history for outside contributions. Reply to this task with, for each repository, either
   "all my own code" or the names and the files an outsider contributed.
2. If an outsider's work is in a ported file, **stop**: that file needs the contributor's
   permission or a clean rewrite. File a follow-up task per file. Do not write the statement
   until the owner decides.

**Decided 2026-10-17:** owner step 1 is done. The owner confirms no outside contributor's code is in any of the five V1 repositories (`jscad-utils`, `jscad-hardware`, `jscad-raspberrypi`, `jscad-gears`, `PiPiece`), so step 2's stop does not apply and step 3 can proceed. This is the owner's answer to the question, not something the agent checked.
3. Once confirmed, add the section to `LICENSING.md`. It says: which files are ported, from
   which V1 library and version; that the author holds the copyright to the ported code and
   relicenses it AGPL-3.0-or-later; that the gear fixtures are measured data, with no V1 source
   vendored; that dimensional values cite their sources in file comments; and where a standard
   or a vendor page is the source.
4. Link the section from the `README.md` provenance paragraph.
5. Optional, outside this repository: correct `@jwc/jscad-gears`' `package.json` licence field
   to match the Hessmer MIT notice. Note it in the closing message and leave it to the owner.
