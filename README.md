# WarpCad

A browser-based parametric CAD application — 2D sketching to 3D solids, CSG
modeling, installable as a PWA, designed to be driven by an AI partner as well
as by hand. See `CLAUDE.md` for the full project brief, `Initial design.md`
for the kickoff design decisions, and `TODO/ROADMAP.md` for the build plan.

![WarpCad with a small model on the grid and the Library panel beside it](docs/screenshots/cube-selected.png)

Illustrations in the docs are generated by Playwright specs in `e2e/docs/` (`npm run docs:media`)
and checked by `e2e/docs-media.spec.js` — see [docs/README.md](docs/README.md).

## Where WarpCad came from

![A montage of models built with JSCAD v1 over the years: a Raspberry Pi parts library, a rabbet box, a spur gear, bolts and washers, Pi cases, a light clamp, a K-cup dispenser and a Bahtinov mask.](docs/images/jscad1-montage.jpg)

WarpCad works the way the author has been building things with JSCAD v1 for years: describe a part
in code, see it rendered, adjust a parameter, and combine parts into assemblies. The
parts above (hardware, Raspberry Pi boards and cases, gears, enclosures) were all built that way.
The Library's Raspberry Pi and Hardware items descend from the `jscad-raspberrypi` and
`jscad-hardware` libraries behind them. The montage is regenerated by `npm run docs:montage`.

## Requirements

Node 24+.

## Install

```
npm install
```

## Develop

```
npm run dev
```

Serves the app at `http://localhost:5183` (a dedicated, strict port — see
`vite.config.js`).

## Test

```
npm run typecheck      # vue-tsc --noEmit
npm run test:unit       # Vitest, watch mode (add -- --run for a single pass)
npm run test:e2e:headless   # Playwright, against a real running app
npm test                # all three, in order, single-pass
```

## Component workshop

```
npm run storybook
```

## Build

```
npm run build
npm run preview   # serve the production build locally
```
