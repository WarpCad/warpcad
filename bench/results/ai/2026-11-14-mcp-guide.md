instructions at their `ai-028` length). The client is a real Claude Code 2.1.322, headless: `claude -p

Notes:

- Every one of the six runs called `record_prompt` first with the user's exact words, then read
  `warpcad://guide` with `ReadMcpResourceTool` **without being told to**, then `describe_scene`.
- "Calls before the first write" counts MCP and resource calls, not the `ToolSearch` that loads the deferred
  tool schemas, and counts `record_prompt` and the guide read as calls.
- The bench's `ambiguous-request` prompt (*make me something nice*) was run twice first and **discarded**:
  those two runs still had Claude Code's default tools, answered with the Artifact page tool and never
  touched WarpCad. The `--tools` cut was added for every later run. The airfoil request is the "ambiguous"
  case `ai-027` row 1 names, so it stands in for it. That is an extra pair of runs beyond the six the row asks
  for, and the discarded pair cost about two cents each.
- The airfoil pair split: one asked, one built. The instructions do not make the model ask every time.
- The model is Haiku, the cheapest, not the model most owners use. Treat the "guide read unasked" result as
  a floor for that model, not a measurement of Sonnet or Opus.
