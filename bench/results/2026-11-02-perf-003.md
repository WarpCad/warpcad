## The request count

The new build adds one request before usable in every engine: the separate `rolldown-runtime` file
(459 bytes gzipped). The `codeSplitting` group keeps it in its own chunk; without the group, Rolldown
produces three initial files (`index`, `visibility`, runtime). Dropping the group changes no byte
totals (601.3 kB with it removed against 600.5 kB with it kept, gzip -6). The owner decided to accept
one extra request rather than change the chunking for 459 bytes.
