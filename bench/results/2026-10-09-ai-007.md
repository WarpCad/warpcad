# `TODO/ai-007`: the assistant's geometry checks on a 100-slice wing

**Machine**: Apple M4 Pro, macOS 27.0, Node v24.14.1.
**Engine**: plain Node (V8), no browser. The checks are framework-free
(`src/core/kernel/measure.js`, `meshQuery.js`, `watertight.js`), so this measures the checks
themselves.
**Fixture**: a lofted wing, 100 sections of a NACA 2412-like airfoil (40 points each), chord
tapering 150 → 90 mm over a 600 mm span: **7,996 triangles**. `primitive.sketch` caps a Loft at
64 slices, so the bench builds the 100-section wing with the same `extrudeFromSlices`
construction its Loft branch uses. The 64-slice wing the app can build (5,116 triangles) is
measured too.
**Method**: `node bench/ai-007-analysis.mjs --runs 9`. One warm-up, then median and worst of 9.

## Where the time goes

The analysis tools run synchronously inside the tool registry, on the main thread, during an
AI turn. They never run in the pan/zoom/drag frame path the 16 ms budget is for. A turn
already pauses the user's edits (decision 5 in `docs/decisions/ai-partner.md`). The
registry's header in `src/ai/tools/index.js` gives the reasoning.

| check | median | worst |
|---|---|---|
| `wallThickness`, 4,000 rays, through the hierarchy (**after**) | **12.8 ms** | 15.3 ms |
| the same rays, flat scan of every triangle (**before**) | 218.6 ms | 230.3 ms |
| `openEdgesOf(makeWatertight(wing))` | 4.6 ms | 6.4 ms |
| `minimumDistance(wing, a copy 5 mm above)` | 14.1 ms | 16.4 ms |
| `wallThickness`, the 64-slice wing the app can build | 8.5 ms | 8.9 ms |
| `analyseGeometry` | 0.0 ms | 0.0 ms |

`analyseGeometry` reads 0.0 ms after the warm-up because `@jscad/modeling` caches volume, area
and centre of mass on the geometry object. The first call on a new body pays for the union and
the measurements.

The "before" row is the obvious implementation without `meshQuery.js`'s bounding volume
hierarchy: about 32 M triangle tests for 4,000 rays. The hierarchy makes the thickness check
**17× faster**, which keeps a whole `check_printability` call under about 20 ms on this wing.

## What it found on the wing

The thinnest wall was 0.058 mm, at the trailing edge, where an airfoil tapers to nothing. There
were 5 separate thin spots under 1.2 mm, one per neighbourhood, and 0 open edges after the
export repair. The gap to a copy placed 5 mm above was 5.000 mm. A real wing would need a
blunted trailing edge to print, and the check says exactly that.
